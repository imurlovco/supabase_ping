# supabase_ping
Automatic ping transmitter to always keep Supabase Database active
## Installation
1. Install Python uv package
   ```bash
   pip install uv
   ```
2. Copy GitHub repository
   ```bash
   git clone https://github.com/Imurlovco/supabase_ping.git
   ```
3. Move to folder and sync requirements via uv
   ```bash
   cd supabase_ping && uv sync
   ```
4. Enable virtual environment and start developing
   ```bash
   source .venv/Scripts/activate
   ```
   ###### Please use commands appropriate for your OS and CLI environment.
